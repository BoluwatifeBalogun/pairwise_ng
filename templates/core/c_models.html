How the scores are measured

Each held-out project description is treated as a new student's interest statement. The supervisor who actually handled that project is the correct answer. Supervisor profiles are rebuilt without the held-out records before scoring.

Top-1
The correct supervisor is ranked first.
Top-3
The correct supervisor is in the first three.
MRR
Average of one divided by the correct supervisor's rank.

Adding a fine-tuned round

  1. Export the training files: python manage.py export_training_data
  2. Fine-tune on a GPU machine: python training/finetune_sbert.py --round 1
  3. Copy the output folder into models/ and register it: python manage.py register_model sbert-round-1 --round 1 --activate

{% icon "info" %}A round is activated only if it does not score worse than the current version on the held-out records.
